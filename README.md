HTML Experiments:-

This repository contains HTML experiments completed as part of a Web Development course.

Experiments:-

- Experiment 1: Headings, Paragraphs, Text Formatting, Special Characters, and Lists in HTML.
- Experiment 2: College Timetable using HTML Tables, Rowspan, Colspan, Headers, Captions, and Nested Tables.
- Experiment 3: Global Daily News Webpage using HTML.
- Experiment 4: Hotel Room Booking Form using HTML Forms.

Technologies Used:-

- HTML5
- Visual Studio Code
